# Test-Driven Development

## Overview
Enforces the Red-Green-Refactor discipline to ensure high test coverage and verifiable correctness.

## When to Use
- Implementing cryptographic routines, session validators, permission checks, and server actions.

## Process
1. **Red**: Define the test asserting expected behavior and edge cases.
2. **Green**: Write the minimal code required to pass the assertion.
3. **Refactor**: Clean up the implementation while keeping all tests passing.
