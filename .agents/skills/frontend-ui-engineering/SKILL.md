# Frontend UI Engineering

## Overview
Standards and workflows for building premium, responsive, accessible web interfaces.

## Standards
- **Aesthetic Excellence**: Dark mode palettes, glassmorphism (`backdrop-blur`), subtle borders (`border-zinc-800`), smooth hover transitions.
- **Component Isolation**: Reusable components placed in `src/components/`, decoupled from route pages.
- **Micro-animations**: Smooth feedback on button clicks, form submissions, and modal toggles.
- **Accessibility**: Keyboard navigable, proper ARIA labels, semantic HTML tags.
